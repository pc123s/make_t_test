# 做T参考工具

按 `说明.md` 要求做的本地交易测试工具（做T模拟）。

## 怎么运行

直接**双击 `index.html`** 即可（无需联网、无需装环境，浏览器本地打开即可）。

> 依赖同目录下 3 个文件：`index.html` + `echarts.min.js` + `data.js`，缺一不可。

## 功能

- **主图**：159952 广发创业板ETF，K线 + 成交量 + MA5/10/20/30/60/144/250
- **副图**：上证指数，同样指标
- **日线 / 5分钟一键切换**（两图联动缩放）
- **无交易日空隙**：类目轴连续显示，周末/节假日自动跳过
- **训练模式**（右侧开关）：只有开启后才能买卖
  - 「下一步/上一步」（日线=下一天，5分钟=下一根）按 K 线收盘价推进时间，实时结算浮动盈亏
  - 也可用键盘 ← → 方向键推进；点 K 线可回退到该根
  - 关闭训练模式后自由缩放浏览全图
- **买卖**：输入份额买入/卖出，实时显示金额、持仓、成本、市值、现金、浮动盈亏、已实现盈亏、总资产、总收益
- **均线可增删**：默认 7 条在图例点击即可隐藏/显示；右侧可新增任意周期（如 17）并可删除
- **归零**：一键清零并自动导出买卖记录 CSV（含 BOM，Excel 直接打开）

## 训练模式用法

1. 先在「浏览」模式下点某根 K 线，设定参考价/训练起点（不想设就用默认：日线最近 120 根、5 分钟最近 240 根）。
2. 点「训练模式」开关打开 → 右侧可买卖。
3. 买入后点「下一天/下一根」推进，收益随收盘价自动结算。
4. 觉得到位了就卖出；训练结束点「归零并导出CSV」保存记录。

## 数据

- 日线：全量（2017 至今）
- 5分钟：默认保留最近 **250 个交易日**（约一年）

想保留更多/更少 5 分钟数据，重新生成 `data.js`：

```
D:\Python37\python.exe _build_data.py 500   # 500 个交易日
```

## 说明

- 买卖价按「参考价/当前价」成交（训练模式=当前K线收盘价）。
- 本工具为模拟盘，不做真实下单、不含手续费/印花税。
